# Learn, Reference: findable and dated

**Loop:** learn

Material worth keeping that isn't a PRD: research findings, external API notes, comparisons, how-tos the team keeps rediscovering.

- Store it where the project keeps references, and link it from the PRDs that rely on it. A reference no PRD links to tends to rot.
- Give each reference a source and an as-of date. A reference about an external system is only as good as its capture date.
- Promote, don't duplicate. If a reference turns into a description of how *our* feature works, it belongs in the PRD.
- References never hold credentials, hostnames, usernames, or machine-specific absolute paths.
